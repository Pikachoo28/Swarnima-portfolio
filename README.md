# Swarnima Asthana Portfolio

A responsive static portfolio website for Swarnima Asthana, Senior Mobile Application Developer.

## Files
- index.html — complete website
- assets/ — project screenshots
- Swarnima_Asthana_Resume.pdf — supplied resume

## Run locally

## Deploy
